## 6. KEY RESPONSIVE PRINCIPLES

### DO ✅
- Stack everything on mobile (1 column)
- Use touch-friendly buttons (min 44px)
- Make text readable (min 16px font)
- Hide non-essential elements on mobile
- Use full width on mobile
- Stack images vertically
- Responsive images (100% width)

### DON'T ❌
- Use small text (<14px)
- Tiny tap targets
- Horizontal scrolling (except sliders)
- 3+ columns on mobile
- Fixed widths
- Absolute positioning
- Desktop-only features

---

## 7. RESPONSIVE IMPLEMENTATION CHECKLIST

- [ ] Mobile: 320px-480px (phones)
- [ ] Tablet: 768px-1024px
- [ ] Desktop: 1280px+ (laptops)
- [ ] Images scale perfectly
- [ ] Text is readable
- [ ] Forms are usable
- [ ] No horizontal scrolling
- [ ] Touch targets are 44px+
- [ ] Navigation works on all sizes
- [ ] Tested on real devices
